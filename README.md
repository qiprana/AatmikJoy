## Website migration
The current approved site is the Version 9 watercolor design, packaged separately in `aatmikjoy_github_pages_starter.zip`. The source package needs to be placed at the repository root to preserve the existing design, images, navigation, and reflection links. **Do not publish until the full site has been uploaded and checked.**

Key files in the prepared package:
- `index.html` — Home, Paths, Reflections, Connect, Products and Request to Join prototype
- `assets-watercolor.webp` — shared watercolor background
- `logo.png` — original horizontal logo
- `reflections/what-is-health-and-healing/index.html` — stand-alone article
- `.nojekyll` — GitHub Pages static processing

## Future workflow
Edit source files here; review changes in a branch/PR; merge to `main`; let GitHub Pages deploy the approved version.

For the initial static site, configure **Settings → Pages → Deploy from a branch → main → / (root)** after all site files are present.

After testing the GitHub Pages URL, configure the custom domain `aatmikjoy.me` in Settings → Pages and with the domain registrar. Avoid adding a `CNAME` file until it is configured.

### Important
The Join flow is a preview only. GitHub Pages does not provide member authentication or private health-data storage.
